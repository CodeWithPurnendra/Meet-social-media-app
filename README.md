# 📱 Meet – Social Media App

**Meet** is a modern and responsive social media application built with **React**. Inspired by popular social networking platforms, it provides an engaging user interface where users can explore stories, share posts, interact with content, and enjoy a seamless social media experience.

Designed with a clean and intuitive layout, this project showcases modern React development practices, reusable components, and responsive UI design.

---

## ✨ Features

* 🔐 Modern Login & Signup interface
* 📖 Stories section with user avatars
* 📝 Create and browse social media posts
* ❤️ Like and interact with posts
* 🔍 Search functionality
* 👤 User profile interface
* 📱 Fully responsive design
* ⚡ Fast and smooth user experience
* 🎨 Clean and modern UI

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/CodeWithPurnendra/Meet-social-media-app.git
```

### 2️⃣ Navigate to the Project

```bash
cd Meet-social-media-app
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal to view the application.
