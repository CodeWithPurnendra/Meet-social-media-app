# Meet – Social Media App 🚀

Meet is a modern social media web application built using React.  
It allows users to connect, share posts, view stories, and interact with content in a clean and responsive user interface inspired by popular social media platforms.

---

## ✨ Features

- User-friendly authentication UI (Login / Signup)
- Stories section with avatar images
- Create and view posts
- Like and interact with posts
- Search functionality
- Fully responsive design
- Fast performance using React

---

## 🛠️ Tech Stack

- Frontend: React
- Styling: CSS3, Flexbox
- Icons: React Icons
- State Management: React Hooks
- Version Control: Git & GitHub
